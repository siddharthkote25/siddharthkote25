### 🚀 Featured Projects

#### 🆘 [SafeSteps – IoT Personal Safety & Emergency Response System](https://github.com/[YOUR-USERNAME]/safesteps)
A wearable IoT safety device that sends real-time location and SOS alerts during emergencies.
- Integrated **ESP32 + Neo-6M GPS + A7670C 4G LTE** to trigger one-touch SOS alerts with live location via SMS and voice call
- Achieved a **2–5 second average alert dispatch time** across indoor/outdoor testing
- Built a companion mobile app with live location tracking and a multilingual (English/Hindi/Marathi) assistant, supporting both online and offline operation
- `ESP32` `GPS` `4G LTE` `UART` `Embedded C` `IoT`

#### 🗑️ [Smart Dustbin – Automatic Touch-Free Lid System](https://github.com/[YOUR-USERNAME]/smart-dustbin)
An Arduino-based dustbin that opens its lid automatically when it senses an approaching hand or object.
- Used an **HC-SR04 ultrasonic sensor** for real-time distance sensing
- Controlled a **servo motor via PWM** for smooth, reliable lid actuation
- Designed for hygienic, touch-free waste disposal
- `Arduino Uno` `HC-SR04` `Servo Motor` `PWM`
